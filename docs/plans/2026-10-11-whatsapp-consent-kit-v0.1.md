# WhatsApp Consent Kit v0.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A reusable Python package, `whatsapp-consent-kit`, that any FastAPI + SQLAlchemy + Postgres app embeds to collect, verify, check, honour opt-outs for, and erase WhatsApp consent, released as git tag `v0.1.0`.

**Architecture:** One package (`src/whatsapp_consent`) with domain modules that act on the **host's** SQLAlchemy `Session`, tables in the Postgres schema `whatsapp_consent` with the kit's own Alembic history, a `ConsentKit` object that holds the host's hooks and builds two FastAPI routers (owner API, public pages), Jinja2 pages with no JavaScript, and WhatsApp helpers (Meta webhook parsing, STOP/START handling, message helpers). Tests run against a throwaway Postgres database and a small example host app.

**Tech Stack:** Python ≥ 3.12 (developed on 3.13), uv, SQLAlchemy 2.x, psycopg 3, Alembic, FastAPI, Pydantic v2 + pydantic-settings, Jinja2, itsdangerous, python-multipart, segno; pytest, httpx, ruff, pyright.

**Spec:** `docs/specs/2026-10-11-whatsapp-consent-kit-design.md`

## Global Constraints

- Generic terms only: **owner** (the business; the kit stores only an opaque `owner_id` UUID) and **subject** (the person). No host concepts (coach, user, profile) anywhere in the kit.
- Closed sets are `StrEnum`s from `whatsapp_consent.enums`; the database stores them as text with CHECK constraints written in the migration. `TemplateCategory` values are exactly `MARKETING`, `UTILITY`, `AUTHENTICATION`; no purpose may use `AUTHENTICATION`.
- Purposes and notices are host content loaded with `whatsapp_consent.library`. Notices are never edited (a change is a new version). Purpose labels exist in every `Language` (`en`, `hi`).
- All tables are in schema `whatsapp_consent`. The kit's Alembic version table is `whatsapp_consent.alembic_version`. No foreign keys to host tables. IDs are generated by Python (`uuid4`) with a `gen_random_uuid()` server default. Postgres ≥ 14.
- The kit never opens its own connection inside a host: every function takes the host's `Session`. Only the CLI builds an engine (from `CONSENT_DATABASE_URL`, falling back to `DATABASE_URL`).
- No health data and no free-text fields. The year of birth is used for the age check and **never stored**. Inbound WhatsApp text is **never stored**.
- `consent_events` is append-only (trigger). Only clearing `subject_id` (erasure) and the purge (transaction setting `whatsapp_consent.allow_purge = 'on'`) may change it.
- Tokens are stored as SHA-256 hashes. Codes and phone fingerprints are HMAC-SHA256 under `CONSENT_FINGERPRINT_KEY` (fingerprint input `"phone:" + E.164`).
- Typed codes: 6 digits, 10 minutes, 5 attempts, resend after 60 s, max 3 per number per hour and 10 per day. Click-to-chat codes: `START-` + 6 characters from `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`, 30 minutes.
- Personal links expire after 7 days; one active practice link per owner. Unverified practice-link sign-ups are erased after 30 days. `CONSENT_RETENTION_DAYS` ≥ 365 (default 365).
- `CONSENT_VERIFICATION_METHOD=fake` is refused when `CONSENT_ENVIRONMENT=production`.
- Public pages: no JavaScript, no third-party assets, `noindex`, strict CSP, `Referrer-Policy: no-referrer`, CSRF on every form, English and Hindi text for every string.
- Repo conventions: ruff line length 120, `uv run ruff format . && uv run ruff check --fix . && uv run pyright` clean before each commit, commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A phone typed as `98765 43210`, `+91-98765-43210` or `098765 43210` must become one E.164 number, so lookups, de-duplication, status-by-phone and inbound matching all agree (Tasks 1, 4, 8, 11).
2. Reopening or resubmitting a completed personal link must show "already confirmed" or reuse the pending code, never a 500 or a duplicate subject (Task 8).
3. A parent with two children at the same owner uses one number: two subjects, both on the preferences page, and a STOP from that number withdraws both (Tasks 8, 10, 11).
4. A subject who picked Hindi keeps Hindi through validation errors and the following steps (Task 8).
5. An owner erases a subject while that person is on the code page, holds a preferences link, or sends STOP/START: pages say the link is no longer valid, and inbound events are ignored without errors (Tasks 9, 10, 11).

```python
from pydantic import Field, model_validator
from pydantic_settings import BaseSettings, SettingsConfigDict

from whatsapp_consent.enums import VerificationMethod


class ConsentSettings(BaseSettings):
    """Kit configuration, read from CONSENT_* environment variables (and a local .env file)."""

    model_config = SettingsConfigDict(env_prefix="CONSENT_", env_file=".env", extra="ignore")

    environment: str = Field(default="development", pattern="^(development|test|production)$")
    # Only the CLI and a future standalone service use this; inside a host the kit uses the host's session.
    database_url: str | None = None
    # Base URL where the public pages are served; consent and preference links are built from it.
    public_base_url: str = "http://localhost:8000"
    # Keys phone fingerprints (kept after erasure), codes and derived tokens. Long-lived: replacing it makes
    # existing fingerprints and practice links unmatchable.
    fingerprint_key: str = Field(min_length=32)
    # Signs the short-lived cookie that carries a person through the public pages.
    session_secret: str = Field(min_length=32)
    # How typed codes are delivered: Meta authentication template (host's sender) or `fake` (logged; dev only).
    verification_method: VerificationMethod = VerificationMethod.FAKE
    # Offer "Continue on WhatsApp" (the person sends START-XXXXXX to the owner's number) when the owner has one.
    click_to_chat: bool = False
    # For checking X-Hub-Signature-256 on Meta webhooks (optional; hosts may check signatures themselves).
    meta_app_secret: str | None = None
    # Anonymised history is kept this long after erasure (DPDP Rules 8(3): at least a year).
    retention_days: int = Field(default=365, ge=365)
    # Public form submissions (consent, preference lookup, code resend) allowed per IP address per hour.
    web_submissions_per_ip_hour: int = Field(default=20, ge=1)

    @model_validator(mode="after")
    def _check_verification(self) -> "ConsentSettings":
        if self.verification_method == VerificationMethod.CLICK_TO_CHAT:
            raise ValueError("Click-to-chat is enabled with CONSENT_CLICK_TO_CHAT, not as the verification method")
        if self.environment == "production" and self.verification_method == VerificationMethod.FAKE:
            raise ValueError("CONSENT_VERIFICATION_METHOD=fake is not allowed in production")
        return self


class DatabaseUrlSettings(BaseSettings):
    """The CLI's database URL: CONSENT_DATABASE_URL, falling back to the host's DATABASE_URL."""

    model_config = SettingsConfigDict(env_file=".env", extra="ignore")

    consent_database_url: str | None = None
    database_url: str | None = None

    def url(self) -> str:
        url = self.consent_database_url or self.database_url
        if not url:
            raise RuntimeError("Set CONSENT_DATABASE_URL or DATABASE_URL")
        return url
```

`src/whatsapp_consent/phones.py`:

```python
"""Phone numbers as WhatsApp sees them: E.164 (`+919876543210`)."""

import re

E164 = re.compile(r"^\+[1-9][0-9]{6,14}$")
INDIAN_MOBILE = re.compile(r"^\+91[6-9][0-9]{9}$")


class InvalidPhone(ValueError):
    pass


def normalise_phone(raw: str) -> str:
    """Accepts the ways people type Indian mobiles (spaces, dashes, 0 or 91 prefixes) and international +numbers."""
    digits = re.sub(r"[\s\-().]", "", raw.strip())
    if digits.startswith("00"):
        digits = "+" + digits[2:]
    if digits.startswith("+"):
        candidate = digits
    elif re.fullmatch(r"0?[6-9][0-9]{9}", digits):
        candidate = "+91" + digits[-10:]
    elif re.fullmatch(r"91[6-9][0-9]{9}", digits):
        candidate = "+" + digits
    else:
        raise InvalidPhone(raw)
    if not E164.fullmatch(candidate):
        raise InvalidPhone(raw)
    if candidate.startswith("+91") and not INDIAN_MOBILE.fullmatch(candidate):
        raise InvalidPhone(raw)
    return candidate


def mask_phone(phone_e164: str) -> str:
    """`+919876543210` -> `+91 •••••••210`: enough to recognise, not enough to read out."""
    return f"{phone_e164[:3]} {'•' * (len(phone_e164) - 6)}{phone_e164[-3:]}"


def local_display(phone_e164: str) -> str:
    """How an Indian number is usually written (`98765 43210`); other numbers unchanged."""
    if INDIAN_MOBILE.fullmatch(phone_e164):
        return f"{phone_e164[3:8]} {phone_e164[8:]}"
    return phone_e164
```

`src/whatsapp_consent/hashing.py`:

```python
"""Keyed hashes, tokens and codes. Nothing secret is stored in readable form."""

import base64
import hashlib
import hmac
import secrets

CLICK_CODE_ALPHABET = "ABCDEFGHJKLMNPQRSTUVWXYZ23456789"  # no 0/O/1/I
CLICK_CODE_LENGTH = 6


def _hmac(key: str, purpose: str, value: str) -> bytes:
    return hmac.new(key.encode(), f"{purpose}:{value}".encode(), hashlib.sha256).digest()


def keyed_hash(key: str, purpose: str, value: str) -> str:
    """HMAC-SHA256 of `value`, separated by `purpose` so one key serves several uses."""
    return _hmac(key, purpose, value).hex()


def phone_fingerprint(key: str, phone_e164: str) -> str:
    """Matches a number to anonymised records without storing the number."""
    return keyed_hash(key, "phone", phone_e164)


def hash_token(raw: str) -> str:
    return hashlib.sha256(raw.encode()).hexdigest()


def new_token() -> tuple[str, str]:
    """A random URL-safe token and the hash to store."""
    raw = secrets.token_urlsafe(32)
    return raw, hash_token(raw)


def derive_token(key: str, purpose: str, value: str) -> str:
    """A URL-safe token the server can recompute (practice links, which owners re-share)."""
    return base64.urlsafe_b64encode(_hmac(key, f"token:{purpose}", value)).rstrip(b"=").decode()


def new_code() -> str:
    return f"{secrets.randbelow(1_000_000):06d}"


def new_click_code() -> str:
    return "".join(secrets.choice(CLICK_CODE_ALPHABET) for _ in range(CLICK_CODE_LENGTH))


def hash_code(key: str, purpose: str, phone_e164: str, code: str) -> str:
    return keyed_hash(key, f"code:{purpose}:{phone_e164}", code)


def code_matches(key: str, purpose: str, phone_e164: str, code: str, expected_hash: str) -> bool:
    return hmac.compare_digest(hash_code(key, purpose, phone_e164, code).encode(), expected_hash.encode())
```

```python
"""The kit's SQLAlchemy base: every table lives in the `whatsapp_consent` schema."""

import uuid
from enum import StrEnum
from typing import Any

from sqlalchemy import Enum as SAEnum
from sqlalchemy import MetaData, text
from sqlalchemy.orm import DeclarativeBase, mapped_column
from sqlalchemy.types import Uuid

SCHEMA = "whatsapp_consent"

NAMING_CONVENTION = {
    "ix": "ix_%(column_0_label)s",
    "uq": "uq_%(table_name)s_%(column_0_N_name)s",
    "ck": "ck_%(table_name)s_%(constraint_name)s",
    "fk": "fk_%(table_name)s_%(column_0_name)s_%(referred_table_name)s",
    "pk": "pk_%(table_name)s",
}


class ConsentBase(DeclarativeBase):
    metadata = MetaData(schema=SCHEMA, naming_convention=NAMING_CONVENTION)


def enum_column(enum_cls: type[StrEnum], **kwargs: Any) -> Any:
    """A text column holding a StrEnum. The CHECK constraint is written in the migration."""
    column_type = SAEnum(
        enum_cls,
        native_enum=False,
        create_constraint=False,
        length=32,
        validate_strings=True,
        values_callable=lambda members: [m.value for m in members],
    )
    return mapped_column(column_type, **kwargs)


def id_column() -> Any:
    return mapped_column(Uuid, primary_key=True, default=uuid.uuid4, server_default=text("gen_random_uuid()"))
```

```python
"""Loading host content (purposes and notices) from the host's own data migrations.

Purposes are upserted by code. Notices are evidence of what a person was shown, so an existing
(version, language) is never changed: publish a new version instead.
"""

import json
import re
from typing import Any

from sqlalchemy import Connection, text

from whatsapp_consent.enums import Language, TemplateCategory

CODE = re.compile(r"^[a-z][a-z0-9_]{1,31}$")
CONSENTABLE = {TemplateCategory.MARKETING.value, TemplateCategory.UTILITY.value}


class InvalidLibraryContent(ValueError):
    pass


def _check_purpose(row: dict[str, Any]) -> None:
    code = row.get("code", "")
    if not CODE.fullmatch(code):
        raise InvalidLibraryContent(f"purpose code {code!r} must match {CODE.pattern}")
    if row.get("category") not in CONSENTABLE:
        raise InvalidLibraryContent(f"purpose {code}: category must be one of {sorted(CONSENTABLE)}")
    labels = row.get("labels") or {}
    for language in Language:
        label = labels.get(language.value)
        if not label:
            raise InvalidLibraryContent(f"purpose {code}: labels missing language {language.value}")
        for field in ("name", "description"):
            if not str(label.get(field, "")).strip():
                raise InvalidLibraryContent(f"purpose {code}: {language.value} {field} is empty")


def load_purposes(conn: Connection, rows: list[dict[str, Any]]) -> None:
    for row in rows:
        _check_purpose(row)
    conn.execute(
        text(
            """
            INSERT INTO whatsapp_consent.purposes (code, category, labels, position)
            VALUES (:code, :category, CAST(:labels AS jsonb), :position)
            ON CONFLICT (code) DO UPDATE SET
              category = EXCLUDED.category, labels = EXCLUDED.labels, position = EXCLUDED.position
            WHERE (purposes.category, purposes.labels, purposes.position)
              IS DISTINCT FROM (EXCLUDED.category, EXCLUDED.labels, EXCLUDED.position)
            """
        ),
        [
            {"code": r["code"], "category": r["category"], "labels": json.dumps(r["labels"]), "position": r["position"]}
            for r in rows
        ],
    )


def load_notices(conn: Connection, rows: list[dict[str, Any]]) -> None:
    languages = {language.value for language in Language}
    for row in rows:
        if row.get("language") not in languages:
            raise InvalidLibraryContent(f"notice v{row.get('version')}: language must be one of {sorted(languages)}")
        if not all(str(row.get(field, "")).strip() for field in ("title", "summary", "body")):
            raise InvalidLibraryContent(f"notice v{row.get('version')} {row['language']}: title, summary and body are required")
    conn.execute(
        text(
            """
            INSERT INTO whatsapp_consent.notices (version, language, title, summary, body, effective_from)
            VALUES (:version, :language, :title, :summary, :body, CAST(:effective_from AS date))
            ON CONFLICT (version, language) DO NOTHING
            """
        ),
        rows,
    )
```

```python
def latest_notice(db: Session, language: Language, today: date | None = None) -> Notice:
    """The newest notice in effect for a language, falling back to English."""
    today = today or date.today()
    notice = db.scalar(
        select(Notice)
        .where(Notice.language == language, Notice.effective_from <= today)
        .order_by(Notice.version.desc())
        .limit(1)
    )
    if notice is None and language != Language.EN:
        return latest_notice(db, Language.EN, today)
    if notice is None:
        raise LookupError("No consent notice is in effect: load one with whatsapp_consent.library.load_notices")
    return notice
```

```python
"""Recording consent. Every change is a new consent_events row; consent_state follows by trigger."""

import uuid
from dataclasses import dataclass
from datetime import UTC, datetime

from sqlalchemy import select
from sqlalchemy.orm import Session

from whatsapp_consent.enums import ConsentAction, ConsentSource, GivenBy
from whatsapp_consent.models import ConsentEvent, ConsentEvidence, ConsentState, Notice, Purpose, Subject

USER_AGENT_MAX = 500


class UnknownPurpose(ValueError):
    pass


@dataclass(frozen=True)
class Evidence:
    """What the person's device told us when they acted. Deleted on erasure."""

    ip: str | None
    user_agent: str | None


def active_purposes(db: Session) -> list[Purpose]:
    return list(db.scalars(select(Purpose).where(Purpose.is_active).order_by(Purpose.position)))


def purpose_codes(db: Session) -> list[str]:
    return [p.code for p in active_purposes(db)]


def current_consent(db: Session, subject_id: uuid.UUID) -> dict[str, bool]:
    consent = dict.fromkeys(purpose_codes(db), False)
    rows = db.execute(
        select(ConsentState.purpose_code, ConsentState.granted).where(ConsentState.subject_id == subject_id)
    )
    for purpose, granted in rows:
        if purpose in consent:
            consent[purpose] = granted
    return consent


def given_by_for(subject: Subject) -> GivenBy:
    return GivenBy.GUARDIAN if subject.is_minor else GivenBy.SELF


def record_event(
    db: Session,
    subject: Subject,
    *,
    purpose: str,
    action: ConsentAction,
    source: ConsentSource,
    given_by: GivenBy,
    notice: Notice | None = None,
    evidence: Evidence | None = None,
    now: datetime | None = None,
) -> ConsentEvent:
    event = ConsentEvent(
        owner_id=subject.owner_id,
        subject_id=subject.id,
        phone_fingerprint=subject.phone_fingerprint,
        purpose_code=purpose,
        action=action,
        source=source,
        given_by=given_by,
        notice_version=notice.version if notice else None,
        notice_language=notice.language if notice else None,
        verified_at_time=subject.phone_verified_at is not None,
        occurred_at=now or datetime.now(UTC),
    )
    db.add(event)
    db.flush()
    if evidence is not None:
        user_agent = (evidence.user_agent or "")[:USER_AGENT_MAX] or None
        db.add(ConsentEvidence(event_id=event.id, ip=evidence.ip, user_agent=user_agent))
        db.flush()
    return event


def set_consent(
    db: Session,
    subject: Subject,
    wanted: dict[str, bool],
    *,
    source: ConsentSource,
    given_by: GivenBy,
    notice: Notice | None = None,
    evidence: Evidence | None = None,
    now: datetime | None = None,
) -> list[ConsentEvent]:
    """Brings a subject's consent to `wanted`, recording only changes, except that a consent page submission
    records every ticked purpose again: it is a fresh statement against the notice shown."""
    current = current_consent(db, subject.id)
    events = []
    for purpose, granted in wanted.items():
        if purpose not in current:
            raise UnknownPurpose(purpose)
        if current[purpose] != granted or (granted and source == ConsentSource.CONSENT_PAGE):
            action = ConsentAction.GRANTED if granted else ConsentAction.WITHDRAWN
            events.append(
                record_event(
                    db, subject, purpose=purpose, action=action, source=source, given_by=given_by,
                    notice=notice, evidence=evidence, now=now,
                )
            )
    return events
```

```python
"""The single check every outgoing message must pass."""

import uuid

from sqlalchemy import and_, select
from sqlalchemy.orm import Session

from whatsapp_consent.enums import SendBlocker, TemplateCategory
from whatsapp_consent.events import UnknownPurpose, active_purposes, current_consent, purpose_codes
from whatsapp_consent.models import ConsentState, Subject


class AmbiguousCategory(ValueError):
    pass


def send_blockers(subject: Subject, granted: bool) -> list[SendBlocker]:
    blockers: list[SendBlocker] = []
    if not granted:
        blockers.append(SendBlocker.NO_CONSENT)
    if subject.phone_verified_at is None:
        blockers.append(SendBlocker.UNVERIFIED)
    if subject.needs_review:
        blockers.append(SendBlocker.NEEDS_REVIEW)
    if subject.minor_suspended:
        blockers.append(SendBlocker.MINOR_SUSPENDED)
    return blockers


def can_send(db: Session, subject_id: uuid.UUID, purpose: str) -> bool:
    subject = db.get(Subject, subject_id)
    if subject is None:
        return False
    consent = current_consent(db, subject_id)
    if purpose not in consent:
        raise UnknownPurpose(purpose)
    return not send_blockers(subject, consent[purpose])


def can_send_category(db: Session, subject_id: uuid.UUID, category: TemplateCategory) -> bool:
    """By Meta category. AUTHENTICATION (codes the person asked for) is always allowed for a known subject."""
    if category == TemplateCategory.AUTHENTICATION:
        return db.get(Subject, subject_id) is not None
    codes = [p.code for p in active_purposes(db) if p.category == category]
    if len(codes) != 1:
        raise AmbiguousCategory(f"{len(codes)} active purposes use {category}; check by purpose instead")
    return can_send(db, subject_id, codes[0])


def sendable_subjects(db: Session, owner_id: uuid.UUID, purpose: str) -> list[uuid.UUID]:
    """Everyone an owner may message for a purpose right now (a campaign audience), in one query."""
    if purpose not in purpose_codes(db):
        raise UnknownPurpose(purpose)
    granted = and_(
        ConsentState.subject_id == Subject.id, ConsentState.purpose_code == purpose, ConsentState.granted.is_(True)
    )
    query = (
        select(Subject.id)
        .join(ConsentState, granted)
        .where(
            Subject.owner_id == owner_id,
            Subject.phone_verified_at.is_not(None),
            Subject.needs_review.is_(False),
            Subject.minor_suspended.is_(False),
        )
        .order_by(Subject.created_at)
    )
    return list(db.scalars(query))
```

```python
"""Answering "where does this person stand?" for one subject, many, or a phone number."""

import uuid
from dataclasses import dataclass
from datetime import datetime

from sqlalchemy import select
from sqlalchemy.orm import Session

from whatsapp_consent.enums import ConsentAction, Language, SendBlocker, SubjectStatus
from whatsapp_consent.events import purpose_codes
from whatsapp_consent.gate import send_blockers
from whatsapp_consent.hashing import phone_fingerprint
from whatsapp_consent.models import ConsentEvent, ConsentState, Subject
from whatsapp_consent.phones import normalise_phone


@dataclass(frozen=True)
class SubjectState:
    subject_id: uuid.UUID
    owner_id: uuid.UUID
    display_name: str
    status: SubjectStatus
    verified: bool
    consents: dict[str, bool]
    blockers: dict[str, list[SendBlocker]]
    last_changed_at: datetime | None
    notice_version: int | None  # the notice they last agreed against
    notice_language: Language | None

    def can_send(self, purpose: str) -> bool:
        return not self.blockers[purpose]


def subject_status(subject: Subject, consent: dict[str, bool], has_events: bool) -> SubjectStatus:
    if subject.needs_review:
        return SubjectStatus.NEEDS_REVIEW
    if subject.minor_suspended:
        return SubjectStatus.SUSPENDED
    if not has_events:
        return SubjectStatus.INVITED
    if subject.phone_verified_at is None:
        return SubjectStatus.UNVERIFIED
    return SubjectStatus.ACTIVE if any(consent.values()) else SubjectStatus.WITHDRAWN


def states_of(db: Session, subjects: list[Subject]) -> list[SubjectState]:
    """A few queries for any number of subjects."""
    if not subjects:
        return []
    ids = [s.id for s in subjects]
    codes = purpose_codes(db)
    consent = {subject_id: dict.fromkeys(codes, False) for subject_id in ids}
    rows = db.execute(
        select(ConsentState.subject_id, ConsentState.purpose_code, ConsentState.granted).where(
            ConsentState.subject_id.in_(ids)
        )
    )
    for subject_id, purpose, granted in rows:
        if purpose in consent[subject_id]:
            consent[subject_id][purpose] = granted
    latest = {
        row.subject_id: row.occurred_at
        for row in db.execute(
            select(ConsentEvent.subject_id, ConsentEvent.occurred_at)
            .where(ConsentEvent.subject_id.in_(ids))
            .order_by(ConsentEvent.subject_id, ConsentEvent.occurred_at.desc())
            .distinct(ConsentEvent.subject_id)
        )
    }
    agreed = {
        row.subject_id: (row.notice_version, row.notice_language)
        for row in db.execute(
            select(ConsentEvent.subject_id, ConsentEvent.notice_version, ConsentEvent.notice_language)
            .where(
                ConsentEvent.subject_id.in_(ids),
                ConsentEvent.action == ConsentAction.GRANTED,
                ConsentEvent.notice_version.is_not(None),
            )
            .order_by(ConsentEvent.subject_id, ConsentEvent.occurred_at.desc())
            .distinct(ConsentEvent.subject_id)
        )
    }
    states = []
    for subject in subjects:
        subject_consent = consent[subject.id]
        notice_version, notice_language = agreed.get(subject.id, (None, None))
        states.append(
            SubjectState(
                subject_id=subject.id,
                owner_id=subject.owner_id,
                display_name=subject.display_name,
                status=subject_status(subject, subject_consent, subject.id in latest),
                verified=subject.phone_verified_at is not None,
                consents=subject_consent,
                blockers={p: send_blockers(subject, granted) for p, granted in subject_consent.items()},
                last_changed_at=latest.get(subject.id),
                notice_version=notice_version,
                notice_language=notice_language,
            )
        )
    return states


def state_of(db: Session, subject: Subject) -> SubjectState:
    return states_of(db, [subject])[0]


def subjects_by_phone(db: Session, owner_id: uuid.UUID, phone: str, *, key: str) -> list[Subject]:
    """An owner's subjects on a number (a parent may have several children). Raises InvalidPhone."""
    fingerprint = phone_fingerprint(key, normalise_phone(phone))
    query = select(Subject).where(Subject.owner_id == owner_id, Subject.phone_fingerprint == fingerprint)
    return list(db.scalars(query.order_by(Subject.created_at)))


def status_by_phone(db: Session, owner_id: uuid.UUID, phone: str, *, key: str) -> list[SubjectState]:
    return states_of(db, subjects_by_phone(db, owner_id, phone, key=key))
```

```python
import uuid
from dataclasses import dataclass
from datetime import datetime

from sqlalchemy import ColumnElement, select
from sqlalchemy.orm import Session

from whatsapp_consent.enums import ConsentAction, ConsentSource, DataRequestSource, GivenBy, Language
from whatsapp_consent.hashing import phone_fingerprint
from whatsapp_consent.models import ConsentEvent, DataRequest, Subject
from whatsapp_consent.phones import normalise_phone


@dataclass(frozen=True)
class AuditEvent:
    subject_id: uuid.UUID | None  # None once the subject was erased
    purpose: str
    action: ConsentAction
    source: ConsentSource
    given_by: GivenBy
    notice_version: int | None
    notice_language: Language | None
    verified_at_time: bool
    occurred_at: datetime


@dataclass(frozen=True)
class AuditRequest:
    source: DataRequestSource
    requested_at: datetime
    completed_at: datetime | None


@dataclass(frozen=True)
class AuditRecord:
    owner_id: uuid.UUID
    phone_fingerprint: str
    events: list[AuditEvent]
    erasure_requests: list[AuditRequest]


def _record(db: Session, owner_id: uuid.UUID, fingerprint: str, *event_filter: ColumnElement[bool]) -> AuditRecord:
    events = db.scalars(
        select(ConsentEvent).where(ConsentEvent.owner_id == owner_id, *event_filter).order_by(ConsentEvent.occurred_at)
    )
    requests = db.scalars(
        select(DataRequest)
        .where(DataRequest.owner_id == owner_id, DataRequest.phone_fingerprint == fingerprint)
        .order_by(DataRequest.requested_at)
    )
    return AuditRecord(
        owner_id=owner_id,
        phone_fingerprint=fingerprint,
        events=[
            AuditEvent(
                subject_id=e.subject_id, purpose=e.purpose_code, action=e.action, source=e.source,
                given_by=e.given_by, notice_version=e.notice_version, notice_language=e.notice_language,
                verified_at_time=e.verified_at_time, occurred_at=e.occurred_at,
            )
            for e in events
        ],
        erasure_requests=[AuditRequest(r.source, r.requested_at, r.completed_at) for r in requests],
    )


def audit_subject(db: Session, subject_id: uuid.UUID) -> AuditRecord | None:
    subject = db.get(Subject, subject_id)
    if subject is None:
        return None
    return _record(db, subject.owner_id, subject.phone_fingerprint, ConsentEvent.subject_id == subject_id)


def audit_phone(db: Session, owner_id: uuid.UUID, phone: str, *, key: str) -> AuditRecord:
    """Every event for this owner and number, including erased subjects (raises InvalidPhone)."""
    fingerprint = phone_fingerprint(key, normalise_phone(phone))
    return _record(db, owner_id, fingerprint, ConsentEvent.phone_fingerprint == fingerprint)
```

```python
import uuid
from collections.abc import Iterator
from typing import Annotated

from fastapi import FastAPI, Header, HTTPException
from sqlalchemy import create_engine
from sqlalchemy.orm import Session, sessionmaker

from whatsapp_consent.config import ConsentSettings
from whatsapp_consent.kit import ConsentKit, OwnerContext, OwnerInfo

OWNERS: dict[uuid.UUID, OwnerInfo] = {}
ERASED: list[tuple[uuid.UUID, uuid.UUID]] = []  # (owner_id, subject_id) received by the erasure hook

_sessionmaker: sessionmaker[Session] | None = None


def configure_database(url: str) -> None:
    global _sessionmaker
    _sessionmaker = sessionmaker(create_engine(url), expire_on_commit=False)


def session() -> Session:
    assert _sessionmaker is not None, "call configure_database first"
    return _sessionmaker()


def get_db() -> Iterator[Session]:
    with session() as db:
        yield db


def current_owner(x_owner_id: Annotated[str | None, Header()] = None) -> OwnerContext:
    """The host's own sign-in, reduced to a header for tests."""
    try:
        owner_id = uuid.UUID(x_owner_id or "")
    except ValueError:
        raise HTTPException(401, "Not signed in") from None
    info = OWNERS.get(owner_id)
    if info is None:
        raise HTTPException(401, "Not signed in")
    return OwnerContext(owner_id=owner_id, info=info)


def lookup_owner(db: Session, owner_id: uuid.UUID) -> OwnerInfo | None:
    return OWNERS.get(owner_id)


def record_erasure(db: Session, owner_id: uuid.UUID, subject_id: uuid.UUID) -> None:
    ERASED.append((owner_id, subject_id))


def build_kit(settings: ConsentSettings | None = None) -> ConsentKit:
    return ConsentKit(
        settings=settings or ConsentSettings(),  # pyright: ignore[reportCallIssue]
        session_dependency=get_db,
        owner_dependency=current_owner,
        owner_lookup=lookup_owner,
        on_subject_erased=record_erasure,
    )


def build_app(kit: ConsentKit) -> FastAPI:
    app = FastAPI()
    app.include_router(kit.owner_router(prefix="/subjects"))
    return app
```

```python
from sqlalchemy import func, select
from sqlalchemy.orm import Session

from whatsapp_consent.enums import Language, SubjectSource
from whatsapp_consent.hashing import phone_fingerprint
from whatsapp_consent.models import Subject


class DuplicateSubject(Exception):
    pass


def find_subject(db: Session, owner_id: uuid.UUID, phone_e164: str, display_name: str) -> Subject | None:
    """A subject is identified by owner, number and name, so a parent can register several children."""
    return db.scalar(
        select(Subject).where(
            Subject.owner_id == owner_id,
            Subject.phone_e164 == phone_e164,
            func.lower(Subject.display_name) == display_name.lower(),
        )
    )


def create_subject(
    db: Session,
    *,
    owner_id: uuid.UUID,
    display_name: str,
    phone_e164: str,
    birthday_day: int | None,
    birthday_month: int | None,
    is_minor: bool,
    language: Language,
    key: str,
) -> Subject:
    if find_subject(db, owner_id, phone_e164, display_name) is not None:
        raise DuplicateSubject(display_name)
    subject = Subject(
        owner_id=owner_id,
        display_name=display_name,
        phone_e164=phone_e164,
        phone_fingerprint=phone_fingerprint(key, phone_e164),
        birthday_day=birthday_day,
        birthday_month=birthday_month,
        is_minor=is_minor,
        source=SubjectSource.PERSONAL_LINK,
        language=language,
    )
    db.add(subject)
    db.flush()
    return subject
```

```python
"""Consent links. Only token hashes are stored."""

import uuid
from dataclasses import dataclass
from datetime import UTC, datetime, timedelta

from sqlalchemy import select, update
from sqlalchemy.orm import Session

from whatsapp_consent.enums import InviteKind
from whatsapp_consent.hashing import derive_token, hash_token, new_token
from whatsapp_consent.models import Invite, Subject

PERSONAL_INVITE_TTL = timedelta(days=7)


@dataclass(frozen=True)
class IssuedLink:
    invite: Invite
    token: str


def issue_personal_invite(db: Session, subject: Subject, *, minor_only: bool, now: datetime | None = None) -> IssuedLink:
    """A single-use link for one subject. Any earlier link for the subject stops working."""
    now = now or datetime.now(UTC)
    db.execute(
        update(Invite).where(Invite.subject_id == subject.id, Invite.revoked_at.is_(None)).values(revoked_at=now)
    )
    raw, digest = new_token()
    invite = Invite(
        owner_id=subject.owner_id,
        kind=InviteKind.PERSONAL,
        subject_id=subject.id,
        token_hash=digest,
        minor_only=minor_only,
        expires_at=now + PERSONAL_INVITE_TTL,
    )
    db.add(invite)
    db.flush()
    return IssuedLink(invite=invite, token=raw)


def practice_token(key: str, invite_id: uuid.UUID) -> str:
    return derive_token(key, "practice-invite", str(invite_id))


def _active_practice(db: Session, owner_id: uuid.UUID) -> Invite | None:
    return db.scalar(
        select(Invite).where(
            Invite.owner_id == owner_id, Invite.kind == InviteKind.PRACTICE, Invite.revoked_at.is_(None)
        )
    )


def get_practice_invite(db: Session, owner_id: uuid.UUID, *, key: str) -> IssuedLink:
    """The owner's reusable link, created on first use. Its token is derived, so it can be shown again."""
    invite = _active_practice(db, owner_id)
    if invite is None:
        invite_id = uuid.uuid4()
        invite = Invite(
            id=invite_id,
            owner_id=owner_id,
            kind=InviteKind.PRACTICE,
            token_hash=hash_token(practice_token(key, invite_id)),
        )
        db.add(invite)
        db.flush()
    return IssuedLink(invite=invite, token=practice_token(key, invite.id))


def rotate_practice_invite(db: Session, owner_id: uuid.UUID, *, key: str, now: datetime | None = None) -> IssuedLink:
    db.execute(
        update(Invite)
        .where(Invite.owner_id == owner_id, Invite.kind == InviteKind.PRACTICE, Invite.revoked_at.is_(None))
        .values(revoked_at=now or datetime.now(UTC))
    )
    db.flush()
    return get_practice_invite(db, owner_id, key=key)


def resolve_invite(db: Session, raw_token: str, now: datetime | None = None) -> Invite | None:
    """The invite for a token unless revoked or expired. A used personal invite is returned; callers show
    "already confirmed"."""
    now = now or datetime.now(UTC)
    invite = db.scalar(select(Invite).where(Invite.token_hash == hash_token(raw_token)))
    if invite is None or invite.revoked_at is not None:
        return None
    if invite.expires_at is not None and invite.expires_at <= now:
        return None
    return invite
```

```python
"""ConsentKit: a host's configuration, and the kit's public Python API and routers."""

import uuid
from collections.abc import Callable
from dataclasses import dataclass
from typing import Any

from fastapi import APIRouter
from sqlalchemy.orm import Session

from whatsapp_consent.audit import AuditRecord, audit_phone, audit_subject
from whatsapp_consent.config import ConsentSettings
from whatsapp_consent.enums import Language, TemplateCategory
from whatsapp_consent.gate import can_send, can_send_category, sendable_subjects
from whatsapp_consent.models import Subject
from whatsapp_consent.status import SubjectState, state_of, status_by_phone


@dataclass(frozen=True)
class OwnerInfo:
    """What the public pages and share messages say about an owner."""

    display_name: str  # the business named in every opt-in (a Meta requirement)
    language: Language = Language.EN
    whatsapp_number: str | None = None  # E.164; enables click-to-chat verification for this owner


@dataclass(frozen=True)
class OwnerContext:
    """What the host's owner dependency returns for the signed-in owner."""

    owner_id: uuid.UUID
    info: OwnerInfo


OwnerLookup = Callable[[Session, uuid.UUID], OwnerInfo | None]
ErasureHook = Callable[[Session, uuid.UUID, uuid.UUID], None]


class ConsentKit:
    def __init__(
        self,
        *,
        settings: ConsentSettings,
        session_dependency: Callable[..., Any],
        owner_dependency: Callable[..., Any],
        owner_lookup: OwnerLookup,
        sender: Any = None,
        on_subject_erased: ErasureHook | None = None,
    ) -> None:
        """
        session_dependency: the host's FastAPI dependency yielding a SQLAlchemy Session.
        owner_dependency: the host's FastAPI dependency returning OwnerContext (raising its own 401/409).
        owner_lookup: (db, owner_id) -> OwnerInfo | None, for public pages.
        sender: a VerificationSender for authentication-template codes (not needed with the fake method).
        on_subject_erased: (db, owner_id, subject_id) -> None; delete the host's data about the person, same transaction.
        """
        self.settings = settings
        self.session_dependency = session_dependency
        self.owner_dependency = owner_dependency
        self.owner_lookup = owner_lookup
        self.sender = sender
        self.on_subject_erased = on_subject_erased

    @property
    def key(self) -> str:
        return self.settings.fingerprint_key

    # Questions a host asks

    def status(self, db: Session, subject_id: uuid.UUID) -> SubjectState | None:
        subject = db.get(Subject, subject_id)
        return state_of(db, subject) if subject else None

    def status_by_phone(self, db: Session, owner_id: uuid.UUID, phone: str) -> list[SubjectState]:
        return status_by_phone(db, owner_id, phone, key=self.key)

    def can_send(self, db: Session, subject_id: uuid.UUID, purpose: str) -> bool:
        return can_send(db, subject_id, purpose)

    def can_send_category(self, db: Session, subject_id: uuid.UUID, category: TemplateCategory) -> bool:
        return can_send_category(db, subject_id, category)

    def sendable_subjects(self, db: Session, owner_id: uuid.UUID, purpose: str) -> list[uuid.UUID]:
        return sendable_subjects(db, owner_id, purpose)

    def audit(self, db: Session, subject_id: uuid.UUID) -> AuditRecord | None:
        return audit_subject(db, subject_id)

    def audit_by_phone(self, db: Session, owner_id: uuid.UUID, phone: str) -> AuditRecord:
        return audit_phone(db, owner_id, phone, key=self.key)

    # Routers

    def owner_router(self, prefix: str = "/subjects") -> APIRouter:
        from whatsapp_consent.api.router import build_owner_router

        return build_owner_router(self, prefix)
```

```python
"""How typed verification codes reach a phone. The kit never sends anything else."""

import logging
from typing import Protocol

from whatsapp_consent.config import ConsentSettings
from whatsapp_consent.enums import Language, VerificationMethod

log = logging.getLogger("whatsapp_consent.verification")


class DeliveryFailed(Exception):
    """The number couldn't be reached (e.g. it isn't on WhatsApp)."""


class SenderNotConfigured(RuntimeError):
    pass


class VerificationSender(Protocol):
    method: VerificationMethod

    def send_code(self, phone_e164: str, code: str, language: Language) -> None: ...


class FakeSender:
    """Development and test sender: writes the code to the log instead of sending it."""

    method = VerificationMethod.FAKE

    def __init__(self) -> None:
        self.sent: list[tuple[str, str, Language]] = []
        self.fail_for: set[str] = set()

    def send_code(self, phone_e164: str, code: str, language: Language) -> None:
        if phone_e164 in self.fail_for:
            raise DeliveryFailed(phone_e164)
        self.sent.append((phone_e164, code, language))
        log.warning("[fake-whatsapp] verification code %s for %s", code, phone_e164)

    def last_code(self, phone_e164: str) -> str:
        return next(code for phone, code, _ in reversed(self.sent) if phone == phone_e164)


fake_sender = FakeSender()


def resolve_sender(settings: ConsentSettings, sender: VerificationSender | None) -> VerificationSender:
    if settings.verification_method == VerificationMethod.FAKE:
        return fake_sender
    if sender is None:
        raise SenderNotConfigured("CONSENT_VERIFICATION_METHOD=authentication_template needs a sender from the host")
    return sender
```

```python
"""Rate limits stored in Postgres, so they hold across replicas. Keys (IP addresses) are stored hashed."""

from datetime import UTC, datetime, timedelta

from sqlalchemy import func, select
from sqlalchemy.orm import Session

from whatsapp_consent.hashing import keyed_hash
from whatsapp_consent.models import RateLimitEvent


def allow(
    db: Session, *, bucket: str, key: str, limit: int, window: timedelta, hash_key: str, now: datetime | None = None
) -> bool:
    """Records a hit and returns True, or returns False if `limit` hits already happened within `window`."""
    now = now or datetime.now(UTC)
    key_hash = keyed_hash(hash_key, f"ratelimit:{bucket}", key)
    count = db.scalar(
        select(func.count())
        .select_from(RateLimitEvent)
        .where(RateLimitEvent.bucket == bucket, RateLimitEvent.key_hash == key_hash, RateLimitEvent.created_at > now - window)
    )
    if (count or 0) >= limit:
        return False
    db.add(RateLimitEvent(bucket=bucket, key_hash=key_hash, created_at=now))
    db.flush()
    return True
```

```python
import uuid
from datetime import UTC, datetime, timedelta
from typing import Literal

from sqlalchemy import select
from sqlalchemy.orm import Session

from whatsapp_consent.enums import Language, VerificationMethod, VerificationPurpose
from whatsapp_consent.hashing import code_matches, hash_code, new_click_code, new_code
from whatsapp_consent.models import Verification
from whatsapp_consent.senders import DeliveryFailed, VerificationSender

CODE_TTL = timedelta(minutes=10)
CLICK_CODE_TTL = timedelta(minutes=30)
MAX_ATTEMPTS = 5
RESEND_AFTER = timedelta(seconds=60)
MAX_PER_HOUR = 3
MAX_PER_DAY = 10
CLICK_PREFIX = "START-"
CLICK_HASH_PURPOSE = "click"

Reason = Literal["too_soon", "rate_limited", "delivery_failed", "not_found", "expired", "too_many_attempts", "wrong_code"]


class VerificationError(Exception):
    def __init__(self, reason: Reason) -> None:
        super().__init__(reason)
        self.reason: Reason = reason


def start_code_verification(
    db: Session,
    *,
    phone: str,
    purpose: VerificationPurpose,
    language: Language,
    sender: VerificationSender,
    key: str,
    subject_id: uuid.UUID | None = None,
    now: datetime | None = None,
) -> Verification:
    """Sends a 6-digit code. Limits count only codes we sent (not click-to-chat codes)."""
    now = now or datetime.now(UTC)
    recent = db.scalars(
        select(Verification.created_at).where(
            Verification.phone_e164 == phone,
            Verification.method != VerificationMethod.CLICK_TO_CHAT,
            Verification.created_at > now - timedelta(days=1),
        )
    ).all()
    if any(created > now - RESEND_AFTER for created in recent):
        raise VerificationError("too_soon")
    if sum(created > now - timedelta(hours=1) for created in recent) >= MAX_PER_HOUR or len(recent) >= MAX_PER_DAY:
        raise VerificationError("rate_limited")

    code = new_code()
    try:
        sender.send_code(phone, code, language)
    except DeliveryFailed:
        raise VerificationError("delivery_failed") from None
    verification = Verification(
        subject_id=subject_id,
        phone_e164=phone,
        purpose=purpose,
        method=sender.method,
        code_hash=hash_code(key, purpose.value, phone, code),
        expires_at=now + CODE_TTL,
        created_at=now,
    )
    db.add(verification)
    db.flush()
    return verification


def start_click_verification(
    db: Session, *, phone: str, subject_id: uuid.UUID, key: str, now: datetime | None = None
) -> tuple[Verification, str]:
    """A code the person sends to the owner's number (`START-XXXXXX`). Nothing is sent by us."""
    now = now or datetime.now(UTC)
    code = new_click_code()
    verification = Verification(
        subject_id=subject_id,
        phone_e164=phone,
        purpose=VerificationPurpose.CONSENT,
        method=VerificationMethod.CLICK_TO_CHAT,
        code_hash=hash_code(key, CLICK_HASH_PURPOSE, phone, code),
        expires_at=now + CLICK_CODE_TTL,
        created_at=now,
    )
    db.add(verification)
    db.flush()
    return verification, CLICK_PREFIX + code


def check_code(
    db: Session,
    *,
    verification_id: uuid.UUID,
    purpose: VerificationPurpose,
    code: str,
    key: str,
    now: datetime | None = None,
) -> Verification:
    """Marks a typed code verified, or raises. A wrong code increments `attempts` first: commit after catching."""
    now = now or datetime.now(UTC)
    verification = db.get(Verification, verification_id)
    if (
        verification is None
        or verification.purpose != purpose
        or verification.method == VerificationMethod.CLICK_TO_CHAT
        or verification.verified_at is not None
    ):
        raise VerificationError("not_found")
    if verification.attempts >= MAX_ATTEMPTS:
        raise VerificationError("too_many_attempts")
    if now >= verification.expires_at:
        raise VerificationError("expired")
    if not code_matches(key, purpose.value, verification.phone_e164, code.strip(), verification.code_hash):
        verification.attempts += 1
        db.flush()
        raise VerificationError("too_many_attempts" if verification.attempts >= MAX_ATTEMPTS else "wrong_code")
    verification.verified_at = now
    db.flush()
    return verification


def latest_pending(
    db: Session,
    *,
    phone: str,
    purpose: VerificationPurpose,
    subject_id: uuid.UUID | None,
    now: datetime | None = None,
) -> Verification | None:
    """An unexpired, unused typed code for the same phone, purpose and subject (reused on a double submit)."""
    now = now or datetime.now(UTC)
    query = select(Verification).where(
        Verification.phone_e164 == phone,
        Verification.purpose == purpose,
        Verification.method != VerificationMethod.CLICK_TO_CHAT,
        Verification.verified_at.is_(None),
        Verification.expires_at > now,
        Verification.attempts < MAX_ATTEMPTS,
    )
    query = query.where(
        Verification.subject_id.is_(None) if subject_id is None else Verification.subject_id == subject_id
    )
    return db.scalar(query.order_by(Verification.created_at.desc()).limit(1))


def verify_click_code(
    db: Session, *, phone: str, code: str, key: str, now: datetime | None = None
) -> Verification | None:
    """Matches an inbound `START-XXXXXX` from `phone` to an open click-to-chat verification for that number."""
    now = now or datetime.now(UTC)
    candidates = db.scalars(
        select(Verification).where(
            Verification.phone_e164 == phone,
            Verification.method == VerificationMethod.CLICK_TO_CHAT,
            Verification.verified_at.is_(None),
            Verification.expires_at > now,
        )
    )
    for verification in candidates:
        if code_matches(key, CLICK_HASH_PURPOSE, phone, code.strip().upper(), verification.code_hash):
            verification.verified_at = now
            db.flush()
            return verification
    return None
```

```python
"""Rendering public pages with the kit's privacy headers, CSRF protection and the signed flow cookie."""

import hmac
import secrets
from pathlib import Path
from typing import Any
from urllib.parse import urlencode

from fastapi import Request
from fastapi.responses import HTMLResponse, RedirectResponse, Response
from itsdangerous import BadSignature, URLSafeTimedSerializer
from jinja2 import Environment, FileSystemLoader, select_autoescape

from whatsapp_consent.config import ConsentSettings
from whatsapp_consent.enums import Language
from whatsapp_consent.web.i18n import other_lang, t

TEMPLATES_DIR = Path(__file__).parent / "templates"
STATIC_DIR = Path(__file__).parent / "static"

CSRF_COOKIE = "wck_csrf"
FLOW_COOKIE = "wck_flow"
FLOW_MAX_AGE = 30 * 60

SECURITY_HEADERS = {
    "Content-Security-Policy": (
        "default-src 'none'; style-src 'self'; img-src 'self'; form-action 'self'; base-uri 'none'; "
        "frame-ancestors 'none'"
    ),
    "X-Robots-Tag": "noindex, nofollow",
    # Links carry private tokens; never leak them to other sites.
    "Referrer-Policy": "no-referrer",
    "X-Content-Type-Options": "nosniff",
    "Cache-Control": "no-store",
}

_env = Environment(
    loader=FileSystemLoader(TEMPLATES_DIR), autoescape=select_autoescape(["html"]), trim_blocks=True, lstrip_blocks=True
)


def with_headers(response: Response) -> Response:
    response.headers.update(SECURITY_HEADERS)
    return response


class Pages:
    """Everything a public route needs to answer, bound to one kit's settings."""

    def __init__(self, settings: ConsentSettings) -> None:
        self.settings = settings
        self._secure = settings.public_base_url.startswith("https://")
        self._flow = URLSafeTimedSerializer(settings.session_secret, salt="whatsapp-consent-flow")

    def render(self, request: Request, template: str, lang: Language, *, status_code: int = 200, **context: Any) -> HTMLResponse:
        other = other_lang(lang)
        switch_url = None
        if request.method == "GET":
            params = dict(request.query_params) | {"lang": other.value}
            switch_url = f"{request.url.path}?{urlencode(params)}"
        page = _env.get_template(template).render(
            lang=lang,
            t=lambda key, **fmt: t(key, lang, **fmt),
            other_lang=other,
            other_lang_name=t("lang_name", other),
            lang_switch_url=switch_url,
            **context,
        )
        response = HTMLResponse(page, status_code=status_code)
        with_headers(response)
        return response

    def form(self, request: Request, template: str, lang: Language, *, status_code: int = 200, **context: Any) -> HTMLResponse:
        """A page with a form: carries a CSRF token in a hidden field and in a cookie (double submit)."""
        token = request.cookies.get(CSRF_COOKIE) or secrets.token_urlsafe(24)
        response = self.render(request, template, lang, status_code=status_code, csrf=token, **context)
        response.set_cookie(CSRF_COOKIE, token, httponly=True, samesite="strict", secure=self._secure, path="/")
        return response

    def csrf_ok(self, request: Request, submitted: str) -> bool:
        cookie = request.cookies.get(CSRF_COOKIE)
        return bool(cookie and submitted) and hmac.compare_digest(cookie, submitted)

    def message(
        self,
        request: Request,
        lang: Language,
        *,
        title_key: str,
        body_key: str | None = None,
        status_code: int = 200,
        link: str | None = None,
        link_key: str | None = None,
        **fmt: Any,
    ) -> HTMLResponse:
        return self.render(
            request,
            "message.html",
            lang,
            status_code=status_code,
            title=t(title_key, lang, **fmt),
            body=t(body_key, lang, **fmt) if body_key else None,
            link=link,
            link_text=t(link_key, lang) if link_key else None,
        )

    def invalid_link(self, request: Request, lang: Language) -> HTMLResponse:
        return self.message(request, lang, title_key="link_invalid_title", body_key="link_invalid_body", status_code=410)

    def session_expired(self, request: Request, lang: Language) -> HTMLResponse:
        return self.message(request, lang, title_key="session_expired", status_code=403)

    def redirect(self, url: str) -> RedirectResponse:
        response = RedirectResponse(url, status_code=303)
        with_headers(response)
        return response

    def write_flow(self, response: Response, data: dict[str, Any]) -> None:
        """Carries a person between steps (which code, which subject) without server-side sessions."""
        response.set_cookie(
            FLOW_COOKIE, self._flow.dumps(data), max_age=FLOW_MAX_AGE, httponly=True, samesite="lax",
            secure=self._secure, path="/",
        )

    def read_flow(self, request: Request) -> dict[str, Any] | None:
        raw = request.cookies.get(FLOW_COOKIE)
        if not raw:
            return None
        try:
            return self._flow.loads(raw, max_age=FLOW_MAX_AGE)
        except BadSignature:  # includes SignatureExpired
            return None

    def clear_flow(self, response: Response) -> None:
        response.delete_cookie(FLOW_COOKIE, path="/")

    def flow_lang(self, value: str | None, flow: dict[str, Any] | None) -> Language:
        from whatsapp_consent.web.i18n import pick_lang

        return pick_lang(value, pick_lang(flow.get("l") if flow else None, Language.EN))
```

```python
from typing import TYPE_CHECKING, Annotated

from fastapi import APIRouter, Depends, Request
from fastapi.responses import HTMLResponse, Response
from sqlalchemy import select
from sqlalchemy.orm import Session

from whatsapp_consent.enums import Language
from whatsapp_consent.models import Notice
from whatsapp_consent.web.i18n import pick_lang
from whatsapp_consent.web.render import STATIC_DIR, Pages, with_headers

if TYPE_CHECKING:
    from whatsapp_consent.kit import ConsentKit


def build(kit: "ConsentKit", pages: Pages) -> APIRouter:
    router = APIRouter(include_in_schema=False)
    Db = Annotated[Session, Depends(kit.session_dependency)]
    stylesheet = (STATIC_DIR / "consent.css").read_text(encoding="utf-8")

    @router.get("/consent-static/consent.css")
    def css() -> Response:
        return with_headers(Response(stylesheet, media_type="text/css"))

    @router.get("/notice/{version}", response_class=HTMLResponse)
    def notice_page(version: int, request: Request, db: Db, lang: str | None = None) -> HTMLResponse:
        language = pick_lang(lang, Language.EN)
        notice = db.scalar(select(Notice).where(Notice.version == version, Notice.language == language))
        if notice is None:
            return pages.message(request, language, title_key="not_found_title", body_key="not_found_body", status_code=404)
        return pages.render(
            request, "notice.html", language, title=notice.title, notice=notice, paragraphs=notice.body.split("\n\n")
        )

    return router
```

```python
"""What happens when a person submits the consent page, and when their number is then verified."""

from dataclasses import dataclass
from datetime import UTC, datetime

from sqlalchemy import update
from sqlalchemy.orm import Session

from whatsapp_consent.enums import ConsentSource, GivenBy, InviteKind, Language, SubjectSource
from whatsapp_consent.events import Evidence, purpose_codes, set_consent
from whatsapp_consent.hashing import phone_fingerprint
from whatsapp_consent.models import Invite, Notice, Subject
from whatsapp_consent.subjects import find_subject


@dataclass(frozen=True)
class ConsentSubmission:
    for_child: bool
    display_name: str  # the adult's name, or the child's first name
    phone: str  # E.164; the parent's number for a child
    birthday_day: int | None
    birthday_month: int | None
    guardian_name: str | None
    guardian_relation: str | None
    purposes: frozenset[str]
    language: Language


def submit_consent(
    db: Session,
    *,
    invite: Invite,
    submission: ConsentSubmission,
    notice: Notice,
    evidence: Evidence,
    key: str,
    now: datetime | None = None,
) -> Subject:
    """Creates or updates the subject and records consent, unverified until the number is verified."""
    fingerprint = phone_fingerprint(key, submission.phone)
    if invite.kind == InviteKind.PERSONAL:
        subject = db.get(Subject, invite.subject_id)
        if subject is None:
            raise LookupError("The invite's subject no longer exists")
    else:
        subject = find_subject(db, invite.owner_id, submission.phone, submission.display_name)
        if subject is None:
            subject = Subject(
                owner_id=invite.owner_id,
                source=SubjectSource.PRACTICE_LINK,
                needs_review=True,
                display_name=submission.display_name,
                phone_e164=submission.phone,
                phone_fingerprint=fingerprint,
            )
            db.add(subject)
    if subject.phone_e164 != submission.phone:
        subject.phone_e164 = submission.phone
        subject.phone_fingerprint = fingerprint
        subject.phone_verified_at = None  # a different number must be verified again
    subject.display_name = submission.display_name
    subject.birthday_day = submission.birthday_day
    subject.birthday_month = submission.birthday_month
    subject.is_minor = submission.for_child
    subject.guardian_name = submission.guardian_name if submission.for_child else None
    subject.guardian_relation = submission.guardian_relation if submission.for_child else None
    subject.language = submission.language
    db.flush()
    set_consent(
        db,
        subject,
        {code: code in submission.purposes for code in purpose_codes(db)},
        source=ConsentSource.CONSENT_PAGE,
        given_by=GivenBy.GUARDIAN if submission.for_child else GivenBy.SELF,
        notice=notice,
        evidence=evidence,
        now=now,
    )
    return subject


def complete_consent_verification(db: Session, subject: Subject, now: datetime | None = None) -> None:
    """Called after a typed code or a click-to-chat message proves the number."""
    now = now or datetime.now(UTC)
    subject.phone_verified_at = now
    if subject.is_minor and subject.guardian_name is not None:
        subject.minor_suspended = False  # a verified guardian has now consented
    db.execute(
        update(Invite)
        .where(
            Invite.subject_id == subject.id,
            Invite.kind == InviteKind.PERSONAL,
            Invite.used_at.is_(None),
            Invite.revoked_at.is_(None),
        )
        .values(used_at=now)
    )
    db.flush()
```

```python
"""Private links to a verified number's preferences page."""

from datetime import UTC, datetime, timedelta

from sqlalchemy import select, update
from sqlalchemy.orm import Session

from whatsapp_consent.config import ConsentSettings
from whatsapp_consent.hashing import hash_token, new_token
from whatsapp_consent.models import PreferenceLink

PREFERENCE_LINK_TTL = timedelta(days=365)


def issue_preference_link(db: Session, fingerprint: str, now: datetime | None = None) -> str:
    now = now or datetime.now(UTC)
    raw, digest = new_token()
    db.add(PreferenceLink(phone_fingerprint=fingerprint, token_hash=digest, expires_at=now + PREFERENCE_LINK_TTL, created_at=now))
    db.flush()
    return raw


def resolve_preference_link(db: Session, raw_token: str, now: datetime | None = None) -> PreferenceLink | None:
    now = now or datetime.now(UTC)
    link = db.scalar(select(PreferenceLink).where(PreferenceLink.token_hash == hash_token(raw_token)))
    if link is None or link.revoked_at is not None or link.expires_at <= now:
        return None
    return link


def revoke_preference_links(db: Session, fingerprint: str, now: datetime | None = None) -> None:
    db.execute(
        update(PreferenceLink)
        .where(PreferenceLink.phone_fingerprint == fingerprint, PreferenceLink.revoked_at.is_(None))
        .values(revoked_at=now or datetime.now(UTC))
    )


def preference_url(settings: ConsentSettings, token: str) -> str:
    return f"{settings.public_base_url}/p/{token}"
```

```python
"""Validating the consent form. Returns message keys for errors; never raises."""

from dataclasses import dataclass, field
from datetime import date

from whatsapp_consent.enums import Language
from whatsapp_consent.phones import InvalidPhone, normalise_phone
from whatsapp_consent.submissions import ConsentSubmission

NAME_MAX = 80
RELATION_MAX = 40
ADULT_AGE = 18
OLDEST = 120


@dataclass
class ParsedConsent:
    submission: ConsentSubmission | None
    errors: list[str] = field(default_factory=list)
    switch_to_child: bool = False


def empty_consent_values() -> dict:
    return {
        "name": "",
        "phone": "",
        "birth_year": "",
        "birthday_day": "",
        "birthday_month": "",
        "guardian_name": "",
        "guardian_relation": "",
        "child_name": "",
        "declaration": "",
        "purposes": [],
    }


def _int(value: str) -> int | None:
    value = value.strip()
    return int(value) if value.isdigit() else None


def _birthday(day_text: str, month_text: str) -> tuple[int | None, int | None, bool]:
    if not day_text.strip() and not month_text.strip():
        return None, None, True
    day, month = _int(day_text), _int(month_text)
    if day is None or month is None:
        return None, None, False
    try:
        date(2024, month, day)  # a leap year, so 29 February is allowed
    except ValueError:
        return None, None, False
    return day, month, True


def parse_consent_form(
    *,
    who: str,
    name: str,
    phone: str,
    birth_year: str,
    birthday_day: str,
    birthday_month: str,
    guardian_name: str,
    guardian_relation: str,
    child_name: str,
    declaration: str,
    purposes: list[str],
    allowed_purposes: list[str],
    language: Language,
    current_year: int,
) -> ParsedConsent:
    errors: list[str] = []
    guardian: str | None = None
    relation: str | None = None
    if who == "me":
        year = _int(birth_year)
        plausible = year is not None and current_year - OLDEST <= year <= current_year
        # Year only: someone turning 18 this year counts as an adult. The year is never stored.
        if plausible and year is not None and current_year - year < ADULT_AGE:
            return ParsedConsent(None, switch_to_child=True)
        display_name = name.strip()[:NAME_MAX]
        if not display_name:
            errors.append("err_name")
        if not plausible:
            errors.append("err_birth_year")
    else:
        display_name = child_name.strip()[:NAME_MAX]
        guardian = guardian_name.strip()[:NAME_MAX] or None
        relation = guardian_relation.strip()[:RELATION_MAX] or None
        if not guardian or not relation:
            errors.append("err_guardian")
        if not display_name:
            errors.append("err_child_name")
        if declaration != "yes":
            errors.append("err_declaration")

    phone_e164: str | None = None
    try:
        phone_e164 = normalise_phone(phone)
    except InvalidPhone:
        errors.append("err_phone")
    day, month, birthday_ok = _birthday(birthday_day, birthday_month)
    if not birthday_ok:
        errors.append("err_birthday")
    chosen = frozenset(p for p in purposes if p in allowed_purposes)
    if not chosen:
        errors.append("err_purposes")

    if errors or phone_e164 is None:
        return ParsedConsent(None, errors)
    return ParsedConsent(
        ConsentSubmission(
            for_child=who == "child",
            display_name=display_name,
            phone=phone_e164,
            birthday_day=day,
            birthday_month=month,
            guardian_name=guardian,
            guardian_relation=relation,
            purposes=chosen,
            language=language,
        )
    )
```

```python
HOUR = timedelta(hours=1)
FormStr = Annotated[str, Form()]


def client_ip(request: Request) -> str:
    # Behind a proxy, run the server with proxy headers enabled so this is the real client address.
    return request.client.host if request.client else "unknown"


def build(kit: "ConsentKit", pages: Pages) -> APIRouter:
    router = APIRouter(include_in_schema=False)
    Db = Annotated[Session, Depends(kit.session_dependency)]
    settings = kit.settings

    def context(db: Session, token: str) -> "tuple[Invite, OwnerInfo] | None":
        invite = resolve_invite(db, token)
        if invite is None:
            return None
        info = kit.owner_lookup(db, invite.owner_id)
        return (invite, info) if info is not None else None

    def already_done(request: Request, lang: Language) -> HTMLResponse:
        return pages.message(
            request, lang, title_key="already_done_title", body_key="already_done_body",
            link=f"/p?lang={lang.value}", link_key="open_preferences",
        )

    def prefill(db: Session, invite: Invite, who: str) -> dict:
        values = empty_consent_values()
        subject = db.get(Subject, invite.subject_id) if invite.subject_id else None
        if subject is None:
            return values
        phone = local_display(subject.phone_e164)
        if who == "me":
            values |= {"name": subject.display_name, "phone": phone}
        else:
            values |= {
                "child_name": subject.display_name,
                "phone": phone,
                "guardian_name": subject.guardian_name or "",
                "guardian_relation": subject.guardian_relation or "",
            }
        if subject.birthday_day is not None:
            values |= {"birthday_day": str(subject.birthday_day), "birthday_month": str(subject.birthday_month)}
        return values

    def consent_form(
        request: Request, db: Session, lang: Language, invite: Invite, info: "OwnerInfo", token: str, who: str,
        values: dict, errors: list[str], status_code: int = 200,
    ) -> HTMLResponse:
        return pages.form(
            request, "consent_form.html", lang, status_code=status_code, business=info.display_name, token=token,
            who=who, values=values, errors=errors, purposes=active_purposes(db), notice=latest_notice(db, lang),
            months=MONTHS[lang], current_year=date.today().year, minor_only=invite.minor_only,
        )

    def code_page(
        request: Request, db: Session, lang: Language, flow: dict, *, errors: list[str] | None = None,
        sent: bool = False, status_code: int = 200,
    ) -> HTMLResponse:
        verification = db.get(Verification, uuid.UUID(flow["v"])) if flow.get("v") else None
        subject = db.get(Subject, uuid.UUID(flow["s"]))
        if subject is None:
            return pages.invalid_link(request, lang)
        info = kit.owner_lookup(db, subject.owner_id)
        click = None
        if flow.get("c") and info and info.whatsapp_number:
            number = info.whatsapp_number.lstrip("+")
            click = {"url": f"https://wa.me/{number}?text={quote(flow['c'])}", "check_action": "/c/verify/check"}
        phone = verification.phone_e164 if verification else subject.phone_e164
        return pages.form(
            request, "code.html", lang, status_code=status_code, title=t("verify_title", lang),
            intro=t("verify_intro", lang, phone=mask_phone(phone)), action="/c/verify",
            resend_action="/c/verify/resend", submit_label=t("verify_submit", lang), errors=errors or [],
            sent=sent, click=click, business=info.display_name if info else "",
        )

    def finish(db: Session, subject: Subject, lang: Language) -> Response:
        complete_consent_verification(db, subject)
        token = issue_preference_link(db, subject.phone_fingerprint)
        info = kit.owner_lookup(db, subject.owner_id)
        db.commit()
        response = pages.redirect(f"/c/done?lang={lang.value}")
        pages.write_flow(response, {"done": True, "pt": token, "b": info.display_name if info else "", "l": lang.value})
        return response

    # Fixed paths first: /c/verify and /c/done must not be read as tokens.

    @router.get("/c/verify", response_class=HTMLResponse)
    def verify_page(request: Request, db: Db, lang: str | None = None, sent: int = 0) -> Response:
        flow = pages.read_flow(request)
        language = pages.flow_lang(lang, flow)
        if not flow or "s" not in flow:
            return pages.session_expired(request, language)
        if flow.get("v") and db.get(Verification, uuid.UUID(flow["v"])) is None:
            return pages.invalid_link(request, language)  # e.g. the owner erased the subject meanwhile
        return code_page(request, db, language, flow, sent=bool(sent))

    @router.post("/c/verify", response_class=HTMLResponse)
    def verify_submit(request: Request, db: Db, csrf: FormStr = "", lang: FormStr = "", code: FormStr = "") -> Response:
        flow = pages.read_flow(request)
        language = pages.flow_lang(lang, flow)
        if not flow or not flow.get("v") or not pages.csrf_ok(request, csrf):
            return pages.session_expired(request, language)
        subject = db.get(Subject, uuid.UUID(flow["s"]))
        if subject is None or db.get(Verification, uuid.UUID(flow["v"])) is None:
            return pages.invalid_link(request, language)
        try:
            check_code(
                db, verification_id=uuid.UUID(flow["v"]), purpose=VerificationPurpose.CONSENT, code=code, key=kit.key
            )
        except VerificationError as error:
            db.commit()  # keep the attempt count
            return code_page(request, db, language, flow, errors=[f"err_{error.reason}"], status_code=422)
        return finish(db, subject, language)

    @router.post("/c/verify/check", response_class=HTMLResponse)
    def click_check(request: Request, db: Db, csrf: FormStr = "", lang: FormStr = "") -> Response:
        """After sending START-XXXXXX on WhatsApp: the inbound handler has verified the number, or not yet."""
        flow = pages.read_flow(request)
        language = pages.flow_lang(lang, flow)
        if not flow or "s" not in flow or not pages.csrf_ok(request, csrf):
            return pages.session_expired(request, language)
        subject = db.get(Subject, uuid.UUID(flow["s"]))
        if subject is None:
            return pages.invalid_link(request, language)
        if subject.phone_verified_at is None:
            return code_page(request, db, language, flow, errors=["err_not_received_yet"], status_code=422)
        return finish(db, subject, language)

    @router.post("/c/verify/resend", response_class=HTMLResponse)
    def resend(request: Request, db: Db, csrf: FormStr = "", lang: FormStr = "") -> Response:
        flow = pages.read_flow(request)
        language = pages.flow_lang(lang, flow)
        if not flow or not flow.get("v") or not pages.csrf_ok(request, csrf):
            return pages.session_expired(request, language)
        previous = db.get(Verification, uuid.UUID(flow["v"]))
        if previous is None:
            return pages.invalid_link(request, language)
        limit = settings.web_submissions_per_ip_hour
        if not allow(db, bucket="code_resend", key=client_ip(request), limit=limit, window=HOUR, hash_key=kit.key):
            db.commit()
            return code_page(request, db, language, flow, errors=["err_rate_limited"], status_code=429)
        try:
            fresh = start_code_verification(
                db, phone=previous.phone_e164, purpose=VerificationPurpose.CONSENT, language=language,
                sender=kit.sender, key=kit.key, subject_id=previous.subject_id,
            )
        except VerificationError as error:
            db.commit()
            return code_page(request, db, language, flow, errors=[f"err_{error.reason}"], status_code=429)
        db.commit()
        response = pages.redirect(f"/c/verify?lang={language.value}&sent=1")
        pages.write_flow(response, flow | {"v": str(fresh.id)})
        return response

    @router.get("/c/done", response_class=HTMLResponse)
    def done_page(request: Request, lang: str | None = None) -> Response:
        flow = pages.read_flow(request)
        language = pages.flow_lang(lang, flow)
        if not flow or not flow.get("done"):
            return pages.session_expired(request, language)
        return pages.render(
            request, "done.html", language, business=flow["b"], manage_url=preference_url(settings, flow["pt"])
        )

    @router.get("/c/{token}", response_class=HTMLResponse)
    def consent_page(token: str, request: Request, db: Db, lang: str | None = None, who: str | None = None) -> Response:
        found = context(db, token)
        if found is None:
            return pages.invalid_link(request, pick_lang(lang, Language.EN))
        invite, info = found
        language = pick_lang(lang, info.language)
        if invite.used_at is not None:
            return already_done(request, language)
        if invite.minor_only:
            who = "child"
        if who not in ("me", "child"):
            return pages.render(request, "consent_choose.html", language, business=info.display_name, token=token)
        return consent_form(request, db, language, invite, info, token, who, prefill(db, invite, who), [])

    @router.post("/c/{token}", response_class=HTMLResponse)
    def consent_submit(
        token: str,
        request: Request,
        db: Db,
        csrf: FormStr = "",
        lang: FormStr = "",
        who: FormStr = "me",
        name: FormStr = "",
        phone: FormStr = "",
        birth_year: FormStr = "",
        birthday_day: FormStr = "",
        birthday_month: FormStr = "",
        guardian_name: FormStr = "",
        guardian_relation: FormStr = "",
        child_name: FormStr = "",
        declaration: FormStr = "",
        purposes: Annotated[list[str], Form()] = [],  # noqa: B006 (FastAPI copies defaults)
    ) -> Response:
        language = pick_lang(lang, Language.EN)
        found = context(db, token)
        if found is None:
            return pages.invalid_link(request, language)
        invite, info = found
        if invite.used_at is not None:
            return already_done(request, language)
        if not pages.csrf_ok(request, csrf):
            return pages.session_expired(request, language)

        who = "child" if invite.minor_only or who == "child" else "me"
        values = {
            "name": name, "phone": phone, "birth_year": birth_year, "birthday_day": birthday_day,
            "birthday_month": birthday_month, "guardian_name": guardian_name, "guardian_relation": guardian_relation,
            "child_name": child_name, "declaration": declaration, "purposes": purposes,
        }

        def again(errors: list[str], status_code: int = 422, as_who: str = who) -> HTMLResponse:
            return consent_form(request, db, language, invite, info, token, as_who, values, errors, status_code)

        limit = settings.web_submissions_per_ip_hour
        allowed = allow(db, bucket="consent_submit", key=client_ip(request), limit=limit, window=HOUR, hash_key=kit.key)
        db.commit()  # the hit counts even if the form has errors
        if not allowed:
            return again(["err_rate_limited"], 429)

        parsed = parse_consent_form(
            who=who, allowed_purposes=purpose_codes(db), language=language, current_year=date.today().year, **values
        )
        if parsed.switch_to_child:
            values["child_name"] = values["child_name"] or name
            return again(["err_under_18"], 200, "child")
        if parsed.errors or parsed.submission is None:
            return again(parsed.errors)

        try:
            subject = submit_consent(
                db, invite=invite, submission=parsed.submission, notice=latest_notice(db, language),
                evidence=Evidence(client_ip(request), request.headers.get("user-agent")), key=kit.key,
            )
        except IntegrityError:
            db.rollback()
            return again(["err_duplicate"], 409)

        try:
            verification = start_code_verification(
                db, phone=subject.phone_e164, purpose=VerificationPurpose.CONSENT, language=language,
                sender=kit.sender, key=kit.key, subject_id=subject.id,
            )
        except VerificationError as error:
            pending = None
            if error.reason == "too_soon":
                pending = latest_pending(
                    db, phone=subject.phone_e164, purpose=VerificationPurpose.CONSENT, subject_id=subject.id
                )
            if pending is None:
                db.rollback()  # nothing is kept for a number we can't verify right now
                return again([f"err_{error.reason}"], 429 if error.reason in ("too_soon", "rate_limited") else 422)
            verification = pending

        flow = {"v": str(verification.id), "s": str(subject.id), "l": language.value}
        if settings.click_to_chat and info.whatsapp_number:
            _, click_text = start_click_verification(db, phone=subject.phone_e164, subject_id=subject.id, key=kit.key)
            flow["c"] = click_text
        db.commit()
        response = pages.redirect(f"/c/verify?lang={language.value}")
        pages.write_flow(response, flow)
        return response

    return router
```

```python
def test_the_host_hook_runs_in_the_same_transaction(db, make_subject):
    from whatsapp_consent.enums import DataRequestSource
    from whatsapp_consent.erasure import erase_subject
    from whatsapp_consent.models import Subject

    subject = make_subject()
    subject_id = subject.id
    seen = []

    def hook(session, owner_id, erased_id):
        seen.append((session is db, owner_id, erased_id))

    erase_subject(db, subject, source=DataRequestSource.OWNER, on_erased=hook)
    assert seen == [(True, subject.owner_id, subject_id)]

    other = make_subject()
    other_id = other.id

    def failing_hook(session, owner_id, erased_id):
        raise RuntimeError("host could not delete its data")
```

```python
ErasureHook = Callable[[Session, uuid.UUID, uuid.UUID], None]

EVENT_SOURCE = {
    DataRequestSource.SUBJECT: ConsentSource.PREFERENCES_PAGE,
    DataRequestSource.OWNER: ConsentSource.OWNER_RECORDED,
    DataRequestSource.SYSTEM: ConsentSource.SYSTEM,
}
UNVERIFIED_SIGNUP_TTL = timedelta(days=30)
SHORT_LIVED_TTL = timedelta(days=2)  # verification codes and rate-limit hits
SPENT_INVITE_TTL = timedelta(days=30)


def erase_subject(
    db: Session,
    subject: Subject,
    *,
    source: DataRequestSource,
    on_erased: ErasureHook | None = None,
    now: datetime | None = None,
) -> DataRequest:
    """Withdraws all consent, lets the host delete its own data, deletes the subject and its device evidence, and
    keeps the anonymised history. One transaction (the caller commits). Expires the session afterwards."""
    now = now or datetime.now(UTC)
    subject_id, owner_id = subject.id, subject.owner_id
    phone, fingerprint = subject.phone_e164, subject.phone_fingerprint
    request = DataRequest(
        owner_id=owner_id, subject_id=subject_id, phone_fingerprint=fingerprint, source=source, requested_at=now
    )
    db.add(request)
    db.flush()
    set_consent(
        db, subject, dict.fromkeys(purpose_codes(db), False), source=EVENT_SOURCE[source],
        given_by=given_by_for(subject), now=now,
    )
    if on_erased is not None:
        on_erased(db, owner_id, subject_id)

    subject_events = select(ConsentEvent.id).where(ConsentEvent.subject_id == subject_id)
    db.execute(delete(ConsentEvidence).where(ConsentEvidence.event_id.in_(subject_events)))
    db.execute(
        delete(Verification).where(
            or_(
                Verification.subject_id == subject_id,
                and_(Verification.subject_id.is_(None), Verification.phone_e164 == phone),
            )
        )
    )
    db.expunge(subject)
    # ON DELETE SET NULL clears subject_id on consent_events and data_requests; consent_state and invites cascade.
    db.execute(delete(Subject).where(Subject.id == subject_id))
    if not db.scalar(select(func.count()).select_from(Subject).where(Subject.phone_fingerprint == fingerprint)):
        revoke_preference_links(db, fingerprint, now)
    request.completed_at = now
    db.flush()
    db.expire_all()
    return request


def _erase_all(
    db: Session, subject_ids: list[uuid.UUID], source: DataRequestSource, on_erased: ErasureHook | None, now: datetime | None
) -> int:
    for subject_id in subject_ids:
        subject = db.get(Subject, subject_id)
        if subject is not None:
            erase_subject(db, subject, source=source, on_erased=on_erased, now=now)
    return len(subject_ids)


def erase_owner(
    db: Session, owner_id: uuid.UUID, *, on_erased: ErasureHook | None = None, now: datetime | None = None
) -> int:
    """For when an owner closes their account."""
    ids = list(db.scalars(select(Subject.id).where(Subject.owner_id == owner_id)))
    return _erase_all(db, ids, DataRequestSource.OWNER, on_erased, now)


def cleanup_unverified(db: Session, *, on_erased: ErasureHook | None = None, now: datetime | None = None) -> int:
    """Practice-link sign-ups never verified within 30 days are probably mistakes or spam."""
    now = now or datetime.now(UTC)
    ids = list(
        db.scalars(
            select(Subject.id).where(
                Subject.source == SubjectSource.PRACTICE_LINK,
                Subject.phone_verified_at.is_(None),
                Subject.created_at < now - UNVERIFIED_SIGNUP_TTL,
            )
        )
    )
    return _erase_all(db, ids, DataRequestSource.SYSTEM, on_erased, now)


@dataclass
class PurgeResult:
    consent_events: int
    data_requests: int
    verifications: int
    rate_limit_events: int
    invites: int
    preference_links: int


def _deleted(db: Session, statement: Executable) -> int:
    return db.execute(statement).rowcount  # pyright: ignore[reportAttributeAccessIssue]


def purge(db: Session, *, retention_days: int, now: datetime | None = None) -> PurgeResult:
    now = now or datetime.now(UTC)
    cutoff = now - timedelta(days=retention_days)
    db.execute(text("SELECT set_config('whatsapp_consent.allow_purge', 'on', true)"))
    events = _deleted(db, delete(ConsentEvent).where(ConsentEvent.subject_id.is_(None), ConsentEvent.occurred_at < cutoff))
    requests = _deleted(db, delete(DataRequest).where(DataRequest.subject_id.is_(None), DataRequest.completed_at < cutoff))
    db.execute(text("SELECT set_config('whatsapp_consent.allow_purge', 'off', true)"))
    verifications = _deleted(db, delete(Verification).where(Verification.created_at < now - SHORT_LIVED_TTL))
    rate_limit_events = _deleted(db, delete(RateLimitEvent).where(RateLimitEvent.created_at < now - SHORT_LIVED_TTL))
    spent = now - SPENT_INVITE_TTL
    invites = _deleted(
        db,
        delete(Invite).where(
            or_(
                Invite.revoked_at < spent,
                Invite.used_at < spent,
                and_(Invite.kind == InviteKind.PERSONAL, Invite.expires_at < spent),
            )
        ),
    )
    links = _deleted(
        db, delete(PreferenceLink).where(or_(PreferenceLink.revoked_at.is_not(None), PreferenceLink.expires_at < now))
    )
    db.flush()
    return PurgeResult(events, requests, verifications, rate_limit_events, invites, links)


def run_maintenance(
    db: Session, *, retention_days: int, on_erased: ErasureHook | None = None, now: datetime | None = None
) -> dict[str, int]:
    now = now or datetime.now(UTC)
    removed = cleanup_unverified(db, on_erased=on_erased, now=now)
    return {"unverified_signups_removed": removed} | asdict(purge(db, retention_days=retention_days, now=now))
```

```python
"""What a verified number sees on its preferences page: every owner it consented to, separately."""

from collections.abc import Callable
from dataclasses import dataclass
from typing import Any

from sqlalchemy import select
from sqlalchemy.orm import Session

from whatsapp_consent.events import current_consent
from whatsapp_consent.models import Subject


@dataclass(frozen=True)
class PreferenceEntry:
    subject: Subject
    business: str
    consent: dict[str, bool]


def preference_entries(db: Session, fingerprint: str, owner_lookup: Callable[[Session, Any], Any]) -> list[PreferenceEntry]:
    subjects = db.scalars(
        select(Subject)
        .where(Subject.phone_fingerprint == fingerprint, Subject.phone_verified_at.is_not(None))
        .order_by(Subject.created_at)
    )
    entries = []
    for subject in subjects:
        info = owner_lookup(db, subject.owner_id)
        entries.append(
            PreferenceEntry(subject=subject, business=info.display_name if info else "", consent=current_consent(db, subject.id))
        )
    return entries
```

```python
    Db = Annotated[Session, Depends(kit.session_dependency)]
    settings = kit.settings

    def link_invalid(request: Request, lang: Language) -> HTMLResponse:
        return pages.message(
            request, lang, title_key="link_invalid_title", body_key="prefs_link_invalid_body", status_code=410,
            link=f"/p?lang={lang.value}", link_key="lookup_title",

    def not_found(request: Request, lang: Language) -> HTMLResponse:
        return pages.message(request, lang, title_key="not_found_title", body_key="not_found_body", status_code=404)

        if subject is None or subject.phone_fingerprint != link.phone_fingerprint or subject.phone_verified_at is None:
            return None
        return subject

    def lookup_form(request: Request, lang: Language, *, phone: str = "", errors=None, status_code: int = 200) -> HTMLResponse:
        return pages.form(

                  submit_class: str | None = None, errors=None, status_code: int = 200) -> HTMLResponse:
        return pages.form(
            request, "code.html", lang, status_code=status_code, title=title, intro=intro, action=action,
            resend_action=None, submit_label=submit_label, submit_class=submit_class, errors=errors or [],
            sent=False, click=None,

            submit_label=t("verify_submit", lang), errors=errors, status_code=status_code,
        )

        return code_page(

            intro=t("delete_confirm_intro", lang, phone=mask_phone(phone)), action=f"/p/{token}/delete/confirm",
            submit_label=t("delete_submit", lang), submit_class="danger", errors=errors, status_code=status_code,
        )

                    saved: bool = False, errors=None, status_code: int = 200) -> HTMLResponse:
        return pages.form(

            entries=preference_entries(db, link.phone_fingerprint, kit.owner_lookup), purposes=active_purposes(db),
            saved=saved, errors=errors or [], notice=latest_notice(db, lang),

    @router.get("/p", response_class=HTMLResponse)
    def lookup_page(request: Request, lang: str | None = None) -> Response:
        return lookup_form(request, pick_lang(lang, Language.EN))

    @router.post("/p", response_class=HTMLResponse)
    def lookup_submit(request: Request, db: Db, csrf: FormStr = "", lang: FormStr = "", phone: FormStr = "") -> Response:

        if not pages.csrf_ok(request, csrf):
            return pages.session_expired(request, language)
        try:
            phone_e164 = normalise_phone(phone)
        except InvalidPhone:
            return lookup_form(request, language, phone=phone, errors=["err_phone"], status_code=422)
        limit = settings.web_submissions_per_ip_hour
        allowed = allow(db, bucket="prefs_lookup", key=client_ip(request), limit=limit, window=HOUR, hash_key=kit.key)
        db.commit()
        if not allowed:
            return lookup_form(request, language, phone=phone, errors=["err_rate_limited"], status_code=429)

            except VerificationError as error:
                if error.reason == "too_soon":

                    verification_id = str(pending.id) if pending else ""

        pages.write_flow(response, {"pv": verification_id, "l": language.value})

        language = pages.flow_lang(lang, flow)
        if not flow or "pv" not in flow or not pages.csrf_ok(request, csrf):
            return pages.session_expired(request, language)
        if not flow["pv"]:

        try:
            verification = check_code(
                db, verification_id=uuid.UUID(flow["pv"]), purpose=VerificationPurpose.PREFERENCES, code=code, key=kit.key
            )
        except VerificationError as error:
            db.commit()
            reason = "wrong_code" if error.reason == "not_found" else error.reason
            return lookup_code(request, language, errors=[f"err_{reason}"], status_code=422)
        token = issue_preference_link(db, phone_fingerprint(kit.key, verification.phone_e164))
        db.commit()
        response = pages.redirect(f"/p/{token}?lang={language.value}")
        pages.clear_flow(response)
        return response

    @router.get("/p/{token}", response_class=HTMLResponse)
    def preferences_page(token: str, request: Request, db: Db, lang: str | None = None, saved: int = 0) -> Response:
        link = resolve_preference_link(db, token)
        if link is None:
            return link_invalid(request, pick_lang(lang, Language.EN))
        entries = preference_entries(db, link.phone_fingerprint, kit.owner_lookup)
        fallback = entries[0].subject.language if entries else Language.EN
        return preferences(request, db, pick_lang(lang, fallback), token, link, saved=bool(saved))

    @router.post("/p/{token}/subjects/{subject_id}", response_class=HTMLResponse)
    def update_preferences(
        token: str,
        subject_id: uuid.UUID,
        request: Request,
        db: Db,
        csrf: FormStr = "",
        lang: FormStr = "",
        purposes: Annotated[list[str], Form()] = [],  # noqa: B006 (FastAPI copies defaults)
    ) -> Response:

        if not pages.csrf_ok(request, csrf):
            return pages.session_expired(request, language)
        link = resolve_preference_link(db, token)
        if link is None:
            return link_invalid(request, language)
        subject = owned(db, link, subject_id)
        if subject is None:
            return not_found(request, language)
        set_consent(
            db, subject, {code: code in purposes for code in purpose_codes(db)}, source=ConsentSource.PREFERENCES_PAGE,
            given_by=given_by_for(subject), notice=latest_notice(db, language),
            evidence=Evidence(client_ip(request), request.headers.get("user-agent")),
        )
        db.commit()
        return pages.redirect(f"/p/{token}?lang={language.value}&saved=1")

    @router.post("/p/{token}/delete", response_class=HTMLResponse)
    def start_deletion(token: str, request: Request, db: Db, csrf: FormStr = "", lang: FormStr = "", target: FormStr = "") -> Response:
        language = pick_lang(lang, Language.EN)
        if not pages.csrf_ok(request, csrf):
            return pages.session_expired(request, language)
        link = resolve_preference_link(db, token)
        if link is None:
            return link_invalid(request, language)
        subjects = [e.subject for e in preference_entries(db, link.phone_fingerprint, kit.owner_lookup)]
        targets = subjects if target == "all" else [s for s in subjects if str(s.id) == target]
        if not targets:
            return not_found(request, language)
        phone = targets[0].phone_e164
        try:
            verification = start_code_verification(
                db, phone=phone, purpose=VerificationPurpose.DELETION, language=language, sender=kit.sender, key=kit.key
            )
        except VerificationError as error:
            pending = None
            if error.reason == "too_soon":
                pending = latest_pending(db, phone=phone, purpose=VerificationPurpose.DELETION, subject_id=None)
            if pending is None:
                db.commit()
                return preferences(request, db, language, token, link, errors=[f"err_{error.reason}"], status_code=429)
            verification = pending
        db.commit()
        response = pages.redirect(f"/p/{token}/delete?lang={language.value}")
        pages.write_flow(response, {"dv": str(verification.id), "targets": [str(s.id) for s in targets], "l": language.value})
        return response

    @router.get("/p/{token}/delete", response_class=HTMLResponse)
    def deletion_code_page(token: str, request: Request, db: Db, lang: str | None = None) -> Response:
        flow = pages.read_flow(request)
        language = pages.flow_lang(lang, flow)
        if not flow or "dv" not in flow:
            return pages.session_expired(request, language)
        verification = db.get(Verification, uuid.UUID(flow["dv"]))
        if resolve_preference_link(db, token) is None or verification is None:
            return link_invalid(request, language)
        return deletion_code(request, language, token, verification.phone_e164)

    @router.post("/p/{token}/delete/confirm", response_class=HTMLResponse)
    def confirm_deletion(token: str, request: Request, db: Db, csrf: FormStr = "", lang: FormStr = "", code: FormStr = "") -> Response:
        flow = pages.read_flow(request)
        language = pages.flow_lang(lang, flow)
        if not flow or "dv" not in flow or not pages.csrf_ok(request, csrf):
            return pages.session_expired(request, language)
        link = resolve_preference_link(db, token)
        verification_id = uuid.UUID(flow["dv"])
        verification = db.get(Verification, verification_id)
        if link is None or verification is None:
            return link_invalid(request, language)
        phone, fingerprint = verification.phone_e164, link.phone_fingerprint
        try:
            check_code(db, verification_id=verification_id, purpose=VerificationPurpose.DELETION, code=code, key=kit.key)
        except VerificationError as error:
            db.commit()
            return deletion_code(request, language, token, phone, errors=[f"err_{error.reason}"], status_code=422)
        if phone_fingerprint(kit.key, phone) != fingerprint:
            return pages.session_expired(request, language)
        for subject_id in flow["targets"]:
            subject = db.get(Subject, uuid.UUID(subject_id))
            if subject is not None and subject.phone_fingerprint == fingerprint:
                kit.erase_subject(db, subject.id, DataRequestSource.SUBJECT)
        db.commit()
        response = pages.message(
            request, language, title_key="deleted_title", body_key="deleted_body", days=settings.retention_days
        )
        pages.clear_flow(response)
        return response

    return router
```

```python
"""Meta WhatsApp Cloud API webhooks: signature checks and parsing into simple events.

Message text is kept only on the in-memory event, for keyword matching. Never store it.
"""

import hashlib
import hmac
from dataclasses import dataclass
from datetime import UTC, datetime
from typing import Any

from whatsapp_consent.enums import InboundEventType


class InvalidSignature(Exception):
    pass


def verify_signature(raw_body: bytes, header: str | None, app_secret: str) -> None:
    """Checks `X-Hub-Signature-256` (`sha256=<hex HMAC of the raw body with the app secret>`)."""
    expected = "sha256=" + hmac.new(app_secret.encode(), raw_body, hashlib.sha256).hexdigest()
    if not header or not hmac.compare_digest(header.encode(), expected.encode()):
        raise InvalidSignature("webhook signature does not match")


@dataclass(frozen=True)
class InboundEvent:
    type: InboundEventType
    phone_number_id: str  # the business number that received it (the host maps it to an owner)
    phone: str | None  # E.164 of the person: the sender, or the recipient for statuses
    message_id: str | None
    timestamp: datetime | None
    text: str | None = None
    button_payload: str | None = None
    status: str | None = None
    error_codes: tuple[int, ...] = ()


def _e164(wa_id: Any) -> str | None:
    digits = "".join(ch for ch in str(wa_id or "") if ch.isdigit())
    return "+" + digits if digits else None


def _timestamp(value: Any) -> datetime | None:
    try:
        return datetime.fromtimestamp(int(value), tz=UTC)
    except (TypeError, ValueError):
        return None


def parse_webhook(payload: dict[str, Any]) -> list[InboundEvent]:
    events: list[InboundEvent] = []
    for entry in payload.get("entry", []):
        for change in entry.get("changes", []):
            if change.get("field") != "messages":
                continue
            value = change.get("value", {})
            number_id = str(value.get("metadata", {}).get("phone_number_id", ""))
            for message in value.get("messages", []):
                common = {
                    "phone_number_id": number_id,
                    "phone": _e164(message.get("from")),
                    "message_id": message.get("id"),
                    "timestamp": _timestamp(message.get("timestamp")),
                }
                kind = message.get("type")
                if kind == "text":
                    events.append(InboundEvent(InboundEventType.TEXT, text=message.get("text", {}).get("body"), **common))
                elif kind == "button":
                    payload_value = message.get("button", {}).get("payload")
                    events.append(InboundEvent(InboundEventType.BUTTON_REPLY, button_payload=payload_value, **common))
                elif kind == "interactive":
                    interactive = message.get("interactive", {})
                    reply = interactive.get("button_reply") or interactive.get("list_reply") or {}
                    events.append(InboundEvent(InboundEventType.BUTTON_REPLY, button_payload=reply.get("id"), **common))
            for status in value.get("statuses", []):
                codes = tuple(int(error["code"]) for error in status.get("errors", []) if "code" in error)
                events.append(
                    InboundEvent(
                        InboundEventType.ERROR if codes else InboundEventType.STATUS,
                        phone_number_id=number_id,
                        phone=_e164(status.get("recipient_id")),
                        message_id=status.get("id"),
                        timestamp=_timestamp(status.get("timestamp")),
                        status=status.get("status"),
                        error_codes=codes,
                    )
                )
    return events
```

```python
"""Acting on what people send to an owner's WhatsApp number: STOP/START words, button taps, click-to-chat codes and
Meta's marketing opt-out signal. Text is matched in memory and never stored."""

import re
import string
import uuid
from dataclasses import dataclass
from datetime import UTC, datetime

from sqlalchemy import select
from sqlalchemy.orm import Session

from whatsapp_consent.config import ConsentSettings
from whatsapp_consent.enums import ConsentSource, InboundEventType, InboundOutcomeType, TemplateCategory
from whatsapp_consent.events import active_purposes, given_by_for, purpose_codes, set_consent
from whatsapp_consent.meta import InboundEvent
from whatsapp_consent.models import Subject
from whatsapp_consent.preference_links import issue_preference_link, preference_url
from whatsapp_consent.submissions import complete_consent_verification
from whatsapp_consent.verification import verify_click_code

STOP_WORDS = frozenset({"stop", "unsubscribe", "stop all", "रोकें", "बंद", "बंद करें"})
START_WORDS = frozenset({"start", "subscribe"})
CLICK_CODE = re.compile(r"^START-([A-HJ-NP-Z2-9]{6})$")
STOP_BUTTON_PREFIX = "whatsapp_consent:stop:"
MANAGE_BUTTON = "whatsapp_consent:manage"
# Meta's "this person stopped marketing messages" failure. Confirm the code(s) against Meta's documentation before
# relying on it in production (spec §15, open item 1).
MARKETING_OPT_OUT_ERROR_CODES = frozenset({131050})

_SEPARATORS = re.compile(r"[\s" + re.escape(string.punctuation) + "।]+")


@dataclass(frozen=True)
class InboundOutcome:
    type: InboundOutcomeType
    event: InboundEvent
    subject_ids: tuple[uuid.UUID, ...] = ()
    # For the host's reply inside the free 24-hour window ("You're unsubscribed. Manage: <link>").
    preferences_url: str | None = None


def normalise_words(text: str) -> str:
    return " ".join(word for word in _SEPARATORS.split(text.strip().lower()) if word)


def _subjects(db: Session, owner_id: uuid.UUID, phone: str) -> list[Subject]:
    query = select(Subject).where(Subject.owner_id == owner_id, Subject.phone_e164 == phone)
    return list(db.scalars(query.order_by(Subject.created_at)))


def _withdraw(db: Session, subjects: list[Subject], purposes: list[str], source: ConsentSource, now: datetime) -> None:
    for subject in subjects:
        set_consent(db, subject, dict.fromkeys(purposes, False), source=source, given_by=given_by_for(subject), now=now)


def _outcome(
    db: Session, settings: ConsentSettings, kind: InboundOutcomeType, event: InboundEvent, subjects: list[Subject],
    *, with_link: bool,
) -> InboundOutcome:
    url = preference_url(settings, issue_preference_link(db, subjects[0].phone_fingerprint)) if with_link else None
    return InboundOutcome(kind, event, tuple(s.id for s in subjects), url)


def _handle(db: Session, owner_id: uuid.UUID, event: InboundEvent, settings: ConsentSettings, now: datetime) -> InboundOutcome:
    ignored = InboundOutcome(InboundOutcomeType.IGNORED, event)
    if event.phone is None:
        return ignored

    if event.type == InboundEventType.TEXT and event.text:
        click = CLICK_CODE.fullmatch(event.text.strip().upper())
        if click:
            verification = verify_click_code(
                db, phone=event.phone, code=click.group(1), key=settings.fingerprint_key, now=now
            )
            subject = db.get(Subject, verification.subject_id) if verification and verification.subject_id else None
            if subject is None or subject.owner_id != owner_id:
                return ignored
            complete_consent_verification(db, subject, now)
            return InboundOutcome(InboundOutcomeType.VERIFIED, event, (subject.id,))
        subjects = _subjects(db, owner_id, event.phone)
        if not subjects:
            return ignored
        words = normalise_words(event.text)
        if words in STOP_WORDS:
            _withdraw(db, subjects, purpose_codes(db), ConsentSource.WHATSAPP_KEYWORD, now)
            return _outcome(db, settings, InboundOutcomeType.WITHDRAWN, event, subjects, with_link=True)
        if words in START_WORDS:
            # Consent is given on the page, against a notice; START only brings the link.
            return _outcome(db, settings, InboundOutcomeType.SEND_PREFERENCES_LINK, event, subjects, with_link=True)
        return ignored

    if event.type == InboundEventType.BUTTON_REPLY and event.button_payload:
        subjects = _subjects(db, owner_id, event.phone)
        if not subjects:
            return ignored
        if event.button_payload == MANAGE_BUTTON:
            return _outcome(db, settings, InboundOutcomeType.SEND_PREFERENCES_LINK, event, subjects, with_link=True)
        if event.button_payload.startswith(STOP_BUTTON_PREFIX):
            purpose = event.button_payload.removeprefix(STOP_BUTTON_PREFIX)
            if purpose not in purpose_codes(db):
                return ignored
            _withdraw(db, subjects, [purpose], ConsentSource.WHATSAPP_BUTTON, now)
            return _outcome(db, settings, InboundOutcomeType.WITHDRAWN, event, subjects, with_link=True)
        return ignored

    if event.type == InboundEventType.ERROR and MARKETING_OPT_OUT_ERROR_CODES.intersection(event.error_codes):
        subjects = _subjects(db, owner_id, event.phone)
        marketing = [p.code for p in active_purposes(db) if p.category == TemplateCategory.MARKETING]
        if not subjects or not marketing:
            return ignored
        _withdraw(db, subjects, marketing, ConsentSource.META_OPT_OUT, now)
        return _outcome(db, settings, InboundOutcomeType.WITHDRAWN, event, subjects, with_link=False)

    return ignored


def handle_inbound(
    db: Session, *, owner_id: uuid.UUID, events: list[InboundEvent], settings: ConsentSettings, now: datetime | None = None
) -> list[InboundOutcome]:
    """One outcome per event, in order. The caller commits."""
    now = now or datetime.now(UTC)
    return [_handle(db, owner_id, event, settings, now) for event in events]
```

````markdown
| `CONSENT_PUBLIC_BASE_URL` | where the pages are served, e.g. `https://app.example.com` |
| `CONSENT_VERIFICATION_METHOD` | `authentication_template` (pass a sender) or `fake` (logs codes; refused in production) |
| `CONSENT_ENVIRONMENT` | `development`, `test` or `production` |
| `CONSENT_CLICK_TO_CHAT` | `true` to offer "Continue on WhatsApp" when the owner has a number |
| `CONSENT_META_APP_SECRET` | for webhook signature checks |
| `CONSENT_RETENTION_DAYS` | ≥ 365 (default 365) |
| `CONSENT_DATABASE_URL` | for the CLI only; falls back to `DATABASE_URL` |
````
